# Websites catalog hero

Distinct art for `/websites` (optional). Until these exist, `WebsitesHero` reuses Templates hero stills with websites-specific copy.

| File | Purpose |
|---|---|
| `hero-bg-dark.png` | Dark-mode hero still |
| `hero-bg-light.png` | Light-mode hero still |

After adding files, point `components/websites/hero.tsx` at `/websites/hero/…`.
